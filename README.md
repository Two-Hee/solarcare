# 태양광 발전소 DC 전류 채널분석

발전소에서 받은 **채널(스트링)별 DC 암페어 데이터**를 엑셀로 올리면, 채널마다 사이클·트렌드를 그리고
전 채널을 한 차트에서 비교해 **정상 채널과 기준을 벗어나는 채널을 자동으로 분리**하는 도구입니다.
채널 수는 5개든 12개든 20개든 파일에 있는 만큼 그대로 처리합니다.

**[태양광_DC전류_채널분석.html](태양광_DC전류_채널분석.html)** — 파일 하나만 브라우저로 열면 바로 씁니다.
설치도, 서버도, 인터넷 연결도 필요 없습니다.

---

## 무엇을 보여주는가

| 화면 | 답해 주는 질문 |
|---|---|
| **채널 진단 분리** | 지금 어느 채널이 정상이고, 어느 채널이 문제인가 |
| **채널별 일 발전량 트렌드** | 채널마다 날짜에 따라 어떻게 움직였나 · 언제부터 틀어졌나 |
| **전 채널 전류 오버레이** | 하루 사이클에서 다발을 벗어나는 채널은 어느 것인가 |
| **채널별 기간 성능비** | 각 채널이 기준 대비 몇 %인가 = 손실이 얼마인가 |
| **채널 × 날짜 히트맵** | 상시 결함인가, 특정 날짜만의 문제인가 (칸을 누르면 그날로 이동) |
| **일간 발전 프로파일** | 그 채널의 그날 발전 곡선은 어떤 모양인가 |
| **채널별 요약 카드** | 전 채널을 한눈에 훑기 |

## 엑셀로 저장

**`📗 엑셀로 저장`** 버튼을 누르면 분석 내용 전부가 `.xlsx` 한 파일로 떨어집니다.
표만이 아니라 **엑셀 네이티브 차트 3개**가 함께 들어가므로, 파일을 열면 그래프가 바로 보이고
데이터를 고치면 차트도 따라 움직입니다.

| 시트 | 내용 |
|---|---|
| **요약** | 분석 정보 · 판정 기준 · KPI · 채널 진단 분리 · 판정 방법 설명 |
| **채널진단** | 채널별 판정 표 (자동 필터 · 틀 고정) + **기간 성능비 막대 차트** |
| **일별발전량** | 날짜 × 채널 발전량(Ah) + **일 발전량 트렌드 선 차트** |
| **일별성능비** | 채널 × 날짜 성능비 — 화면 히트맵과 **같은 색으로 셀 배경까지 재현** |
| **일간프로파일** | 화면에서 고른 날짜의 시간별 전류 + **발전 프로파일 선 차트** |
| **일별상세** | 채널 × 날짜 전 지표 (발전량·성능비·피크·발전시간·형상왜곡·FF·상관도) |
| **원본데이터** | 업로드한 원본 전류 데이터 |

판정 색상, 백분율·날짜 서식, 틀 고정, 자동 필터가 모두 적용된 상태로 저장되므로
받은 그대로 보고서에 붙이거나 피벗 테이블을 얹을 수 있습니다.
가벼운 텍스트 형식이 필요하면 **`⬇ CSV`** 버튼도 그대로 있습니다.

> 엑셀 파일 생성도 브라우저 안에서만 이뤄집니다. ZIP 압축부터 차트 XML까지 직접 만들기 때문에
> 외부 라이브러리를 전혀 쓰지 않습니다.

## 판정 방법

기준선은 **시각별 전 채널 중앙값**입니다. 평균이 아니라 중앙값을 쓰기 때문에 한두 채널이 고장 나도
기준선이 따라 내려가지 않습니다. 채널마다 일 발전량(Ah, 전류의 사다리꼴 적분)을 기준과 비교해 판정합니다.

| 판정 | 조건 (기본값, 화면에서 조정 가능) |
|---|---|
| **정상** | 아래 어디에도 걸리지 않음 |
| **주의** | 기준보다 12% 초과 발전 · 일별 편차가 12% 초과 · 곡선 형상 왜곡 6% 초과 · 저출력인 날이 있음 |
| **저출력** | 상시 성능비가 기준의 90% 미만 |
| **무발전·고장** | 발전이 사실상 없는 날이 있음 |

지표 네 가지가 서로 다른 고장을 잡습니다.

- **기간 성능비** — 실제 발전량 합 ÷ 기준 발전량 합. 실제 손실을 그대로 보여줍니다.
- **상시 성능비** — 일별 성능비의 중앙값. "평소 실력"이라 중도 고장에는 둔감합니다.
  두 값이 벌어지면 *기간 중간에 고장이 났다*는 뜻입니다.
- **일별 산포** — 일별 성능비의 사분위 범위. 평균은 멀쩡한데 특정 날만 떨어지는 간헐 이상을 잡습니다.
- **곡선 형상 왜곡** — 채널을 그날 성능비로 정규화한 뒤 기준 곡선과의 평균 잔차.
  상시 저출력은 0에 가깝고, **부분 음영·오염처럼 특정 시간대만 파이는 경우에만** 커집니다.

저출력이 이어지기 시작한 첫 날을 **이상 시작일**로 함께 특정합니다.

## 입력 파일 형식

- `.xlsx` / `.xlsm` / `.csv` (엑셀에서 그대로 저장한 파일)
- 첫 행은 열 이름, 한 열은 측정시각, 나머지 열은 채널별 DC 전류(A)
- 시각 열과 채널 열은 **자동 인식**하며, 틀리면 화면에서 바꿀 수 있습니다
- 날짜와 시각이 두 열로 나뉜 형식도 "시각 보조 열"로 합칠 수 있습니다
- 계측 주기는 자동 추정합니다 (1분·5분·15분 등 무엇이든)

데이터가 없어도 **`샘플 데이터로 체험`** 버튼으로 12채널 30일치 가상 데이터를 만들어 동작을 볼 수 있습니다.

## 개인정보

파일은 **브라우저 안에서만** 열리고 분석됩니다. 서버로 전송되지 않으며, 네트워크 요청이 아예 없습니다.
엑셀 압축 해제도 브라우저 내장 `DecompressionStream`으로 처리해 외부 라이브러리를 쓰지 않습니다.

> 최신 Chrome / Edge / Safari / Firefox에서 동작합니다.
> 아주 오래된 브라우저에서 `.xlsx`가 열리지 않으면 엑셀에서 CSV로 저장해 올려 주세요.

## 개발용

```
tools/generate_sample_xlsx.py    # 이상 채널을 주입한 샘플 xlsx/csv 생성 (표준 라이브러리만 사용)
tools/test_core.mjs              # HTML 안의 분석 엔진을 떼어내 Node에서 검증
tools/test_xlsx.mjs              # 엑셀 내보내기를 실행하고 왕복 검증
tools/check_xlsx.py              # 생성된 .xlsx의 패키지 구조·서식·차트 검증
sample/                          # 생성된 샘플 데이터와 분석결과 예시 워크북
```

```bash
python3 tools/generate_sample_xlsx.py   # 샘플 재생성
node tools/test_core.mjs                # 파서 + 판정 로직 검증
node tools/test_xlsx.mjs                # 워크북 생성 + 자체 리더 왕복 검증
pip3 install openpyxl                   # (선택) 아래 검증에 필요
python3 tools/check_xlsx.py sample/분석결과_예시.xlsx
```

`test_core.mjs`는 샘플에 심어 둔 다섯 가지 고장(상시 −18%, 상시 −45%, 부분 음영, 중도 고장, 간헐 이상)을
전부 잡아내는지, 정상 채널 7개를 정상으로 두는지, xlsx와 csv 경로의 결과가 일치하는지를 확인합니다.

`check_xlsx.py`는 ZIP 무결성(CRC), 모든 XML 파트의 적합성, `[Content_Types].xml` 선언 누락,
관계(Relationship) 대상 파트의 실재 여부, 차트가 참조하는 시트 이름을 검사하고,
마지막으로 **openpyxl(엑셀과 무관한 독립 구현)로 실제로 열어** 서식·틀 고정·자동 필터·차트까지 확인합니다.
`sample/분석결과_예시.xlsx`가 그 결과물이라 바로 열어볼 수 있습니다.
